# Raksha Mangasuli — Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript. No build tools or dependencies required.

## Structure

- `index.html` — main page (about, experience, skills, projects, contact)
- `style.css` / `mediaqueries.css` — styles and responsive breakpoints
- `script.js` — small interactive behaviors
- `assets/` — images, icons, and CV
- `blogs/` — individual blog post pages

## Running locally

Just open `index.html` in a browser, or serve the folder locally:

```bash
npx serve .
```

## Deployment

Static site — deploy by pushing the contents of this repo to any static host (GitHub Pages, Netlify, Vercel, etc.).
